# Shamim AI Assistant

Telegram AI Chat Bot powered by Gemini API.

## Features

- Bengali and English chat
- Gemini AI responses
- Telegram inline buttons
- Conversation history
- Clear chat command
- Render deployment ready

## Environment Variables

BOT_TOKEN=your_telegram_bot_token
GEMINI_API_KEY=your_gemini_api_key

## Start

npm install
node index.js
